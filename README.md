# The Strange History Studio

A desktop studio for making ~1 minute history and mystery shorts with AI: research, script, voice, music, animation and render, all in one place.

**[Download the latest version for Windows](https://github.com/TheGivingCircuits/strange-history-studio/releases/latest)**: get the `The-Strange-History-Studio-Setup-x.y.z.exe` file under *Assets*.

- Runs on your own **Claude Pro or Max** plan (sign in once, no API keys). Have ChatGPT or Gemini too? The studio can use them as helpers.
- Voice and music come from **ElevenLabs** through your Claude account's connectors.
- The setup wizard installs and checks everything else for you.
- Updates install themselves: the app tells you when a new version is ready.

Windows may say *"Windows protected your PC"* the first time (the installer isn't signed with a paid certificate yet). Click **More info**, then **Run anyway**.

This repository only hosts the installers.
